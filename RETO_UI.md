# Wonky — Reto UI: dirección de arte no genérica

Esta variante cambia la dirección visual hacia **álbum infantil / sticker dibujado**.

## Cambios principales
- Los iconos principales usan versiones con contorno físico uniforme, en lugar de un shader grueso que variaba de un PNG a otro.
- Se añadieron degradados suaves arriba y abajo para que el HUD se lea sin crear barras rectangulares.
- El dock de habitaciones usa ilustraciones más grandes, nombres visibles y una mancha orgánica amarilla para marcar la habitación activa.
- El HUD de necesidades fue simplificado: icono mayor, texto más pequeño y medidor delgado tipo juguete.
- Las barras ya no parecen ProgressBar estándar: pista crema, tinta oscura y rellenos vivos.
- Baño y Minijuegos ganan tamaño y presencia.
- La pelota permanece eliminada del cuarto de juegos.
- Ajustes usa un marco ilustrado propio con cabecera y detalles decorativos, en vez de una tarjeta beige genérica.
- El menú de minijuegos elimina marcos innecesarios y utiliza las versiones de iconos contorneadas.

No se modificó la lógica de guardado, monedas, estadísticas, inventario ni minijuegos.

# Wonky - Android

Proyecto Godot 4 de mascota virtual preparado con interfaz vertical 1080x1920.

## Abrir

1. Abre Godot 4.
2. Importa `project.godot`.
3. Espera a que termine la importacion inicial.
4. Ejecuta con F6/F5.

## Recursos visuales

- `imagenes/opt/`: imagenes optimizadas usadas por el juego.
- `imagenes/*`: originales de alta resolucion conservados como fuente.
- `assets/wonky/`: frames de animacion que usa `resources/wonky_animations.tres`.
- `animaciones/`: fuentes originales conservadas como respaldo y excluidas de importacion con `.gdignore`.

Los fondos actuales se dejaron sin cambios para trabajarlos en una etapa posterior.

Consulta `LEEME_PRIMERO.txt` para el detalle de las modificaciones.
